# MERN Email App

Full-stack MERN application with TypeScript.

## Features
- **Auth**: Register, Login (timestamp recorded), Logout (timestamp recorded)
- **CRUD**: Create, Read, Delete contacts (email, date, description)
- **Calendar View**: Visual calendar showing contacts by date
- **Send Email**: Template "Hi Salam kenal" via Nodemailer
- **TypeScript**: Both backend and frontend

## Tech Stack
- **Backend**: Express, TypeScript, MongoDB, Mongoose, JWT, bcrypt, Nodemailer
- **Frontend**: React, TypeScript, Vite, Tailwind CSS

## Run Locally
```bash
# Backend
cd backend && npm install && npm run dev

# Frontend (new terminal)
cd frontend && npm install && npm run dev
```

Access at http://localhost:5173
